## How a Website Loads

When a user enters a URL in a browser, the browser first identifies the website address. For domain names, DNS translates the domain into an IP address. The browser then sends an HTTP request to the server. The server responds with the requested website files, and the browser processes the HTML, CSS, and JavaScript to display the webpage.

## Command Prompt Practice
